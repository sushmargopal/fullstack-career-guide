# Full Stack Developer Career Guide — Interactive Presentation

An interactive, single-file HTML/CSS/JS classroom presentation (19 slides) with popups, quizzes, flow diagrams and fun facts. No dependencies, works offline.

**Live:** https://sushmargopal.github.io/fullstack-career-guide/

## Controls
← → / PageUp / PageDown / Space — navigate · Home / End — first / last · `F` fullscreen · `O` overview · `T` timer · `Q` quiz · `?` help · Esc closes popups. Swipe on touch devices.

## Run locally
Open `index.html` in any modern browser.
